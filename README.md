# Fleteshare Frontend

Frontend de Fleteshare, construido con React, Vite y TypeScript.

## Requisitos

- Node.js (versión recomendada: 18.x o superior)
- npm (v9.x o superior)

## Instalación

1. **Cloná el repositorio:**

   ```bash
   git clone https://github.com/tu-usuario/fleteshare-frontend.git
   cd fleteshare-frontend
   ```

2. **Instalá las dependencias:**

   ```bash
   npm install
   ```

## Uso en desarrollo

1. **Iniciá el servidor de desarrollo:**

   ```bash
   npm run dev
   ```


2. **Abrí tu navegador en** [http://localhost:5173](http://localhost:5173) (o la URL que indique la terminal).
